# Linux File Manager

A simple command-line Linux File Manager built using Bash scripting. This project allows users to perform common file and directory management tasks through an interactive menu.

## Features

The Linux File Manager can:

* Create directories
* Create files
* Rename files
* Delete files
* Delete directories
* List files in a directory
* Display hidden files
* Search for a file within a directory
* Search for a word within files in a directory
* Backup files
* Backup directories
* Create a backup directory if it does not already exist

## Technologies Used

* Bash Scripting
* Linux Command Line

## Commands and Concepts Used

This project applies several Linux commands and Bash scripting concepts, including:

* `mkdir` – Create directories
* `touch` – Create files
* `mv` – Rename files
* `rm` – Delete files and directories
* `rmdir` – Remove empty directories
* `ls` – List files and directories
* `find` – Search for files
* `grep` – Search for words within files
* `cp` – Backup files and directories
* `chmod` – Manage file permissions
* `if` statements
* `case` statements
* Loops
* User input using `read`
* File and directory tests using `-f` and `-d`
* Exit status checking using `$?`

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/henryofonedu/Linux-File-Manager.git
```

### 2. Navigate to the Project Directory

```bash
cd Linux-File-Manager
```

### 3. Make the Script Executable

```bash
chmod +x linuxfilemanager.sh
```

### 4. Run the Script

```bash
./linuxfilemanager.sh
```

## Project Purpose

This project was built as a practical exercise while learning Linux and Bash scripting. The goal was to apply the concepts learned by building an interactive program capable of performing common file and directory management operations.
